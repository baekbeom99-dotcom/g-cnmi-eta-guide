# 괌 ETA 신청 도우미

학부모님과 조부모님이 괌 여행 전자허가(G-CNMI ETA)를 한 단계씩 따라 신청할 수 있도록 만든 안내 웹앱입니다.

- 실제 신청은 공식 사이트(https://g-cnmi-eta.cbp.dhs.gov)에서만 할 수 있으며, 신청은 무료입니다.
- `index.html`: 배포용 파일 (GitHub Pages)
- `eta-guide.html`: 수정용 원본 (Claude 아티팩트용, `<head>` 없음)

`eta-guide.html`을 고친 뒤에는 `index.html`도 같이 고쳐야 합니다.
